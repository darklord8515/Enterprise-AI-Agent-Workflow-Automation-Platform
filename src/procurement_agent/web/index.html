      How it works

      Every finding is tied to a sentence in a supplier document.

      A LangGraph workflow plans the checks, retrieves evidence with hybrid search, and assesses each requirement. A deterministic reviewer then rejects any conclusion whose quote cannot be found verbatim in a retrieved supplier source.

      Met

      A supplier document explicitly states the requirement is satisfied, and the quote is verified.

      Gap identified

      A supplier document explicitly shows it is not satisfied: missing, expired, below threshold or only planned.

      Insufficient evidence

      Nothing retrieved settles it. Silence is never treated as compliance.
